# ATSC 3.0 Standards Comparison

Comparison of next-generation digital terrestrial television standards — **ITU-R · ATSC (US) · TTA (Korea) · SBTVD Forum (Brazil)** — anchored to the ATSC 3.0 document set.

Live page: https://sunghojeon.github.io/atsc3-kr-us-br-dashboard/

## Structure

- **Rows** — ATSC 3.0 documents, grouped by number series (A/200–A/300 System, A/320 Physical Layer, A/330 Management and Protocols, A/340 Presentation, A/350, A/360 Security, A/370 Redistribution, A/380) plus a *Datacasting services* group (NRT delivery, broadcast RTK / HP-GNSS correction data, traffic and travel information, emergency information).
- **Columns** — ITU-R, ATSC (baseline), TTA, SBTVD Forum, and a verdict against the ATSC baseline:
  ✓ Same · △ Partial match · ≠ Different · — No counterpart · ⓘ Review needed.
- **Regulatory technical standards** — national rules mapped clause by clause to ATSC documents: Korea (MSIT Notice No. 2023-34, Article 13), United States (47 CFR § 73.682(f)), Brazil (to be added).
- Click a row for the summary, per-organization documents, impact, recommendation, evidence and review history.

Document titles are shown in the language of the issuing body (English, Korean, Portuguese); the official English title is shown alongside only when the issuing body provides one — no in-house translations.

## Layout

```
index.html            static page (no build step, no dependencies)
data/standards.json   comparison data — generated by tools/build_data.py
tools/build_data.py   builds the data file from standards/*/index.csv and the mapping tables
tools/tta_*.py        Playwright (Edge) helpers used to collect TTA documents
docs/refs/            regulation excerpts (KR Article 13, US § 73.682(f)); reference PDFs are git-ignored
standards/            original standard documents (git-ignored — copyright)
```

## Run locally

```bash
python -m http.server 8080      # then open http://localhost:8080/
python tools/build_data.py      # regenerate data/standards.json after editing the mapping
```
