# ATSC 3.0 표준 비교 대시보드 (한국 · 미국 · 브라질)

한국(KR), 미국(US), 브라질(BR)의 차세대 지상파 방송 표준을 항목별로 비교하는 인터랙티브 대시보드입니다.

| 국가 | 표준 | 비고 |
|------|------|------|
| 🇰🇷 한국 | ATSC 3.0 (TTAK.KO-07.0127 계열) | 2017년 UHD 본방송 시작, MMT 기반 |
| 🇺🇸 미국 | ATSC 3.0 (A/300 계열, "NextGen TV") | ROUTE/DASH 위주, 2020년 상용 시작 |
| 🇧🇷 브라질 | TV 3.0 (ATSC 3.0 물리계층 + 자체 상위계층) | SBTVD Forum, 2025년 이후 단계적 도입 |

## 비교 축 (초안)
- 물리계층 (PHY): 채널 대역폭, 파일럿, LDM, 부트스트랩
- 전송계층: ROUTE/DASH vs MMT
- 비디오/오디오 코덱: HEVC / VVC, AC-4 / MPEG-H
- 방송-통신 융합(하이브리드), 앱 프레임워크(A/344, Ginga 등)
- 재난경보 (AEA / KEAS), 접근성, 저작권 보호
- 규제·정책 및 도입 일정

## 구조
```
data/    비교 데이터 (JSON)
src/     대시보드 소스
docs/    참고 문서·표준 출처 정리
```

## 실행
```bash
# 정적 대시보드: 로컬 서버로 index.html 서빙
python -m http.server 8080
```
