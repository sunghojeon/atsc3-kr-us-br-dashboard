# 47 CFR §73.682(f) and the ATSC comparison baseline

Checked 18 October 2026 against [eCFR](https://www.ecfr.gov/current/title-47/section-73.682). The following is a rule summary, not a verbatim quotation.

- Paragraph (f)(2)(i) incorporates **A/321:2016**, dated 23 March 2016. Where virtual channels are used, major-channel assignment also follows the incorporated A/65C:2006 Annex B.
- Paragraph (f)(2)(ii) incorporates **A/322:2017**, dated 6 June 2017, for transmission of **at least one free over-the-air primary video programming stream**.
- Paragraph (f)(2)(iii) sunsets that (ii) condition on **17 July 2027**. It does not assign that sunset to the A/321 condition.

The latest voluntary ATSC editions are a separate technical comparison baseline. FCC fixed incorporation does not automatically update when ATSC publishes a new edition. This section alone does not establish every receiver, codec, application or security requirement.

The earlier compressed excerpt was preserved in the independent review's implementation preimages before this correction.
