# 2026-10-22 비교 자료 갱신

2026-10-18판을 바탕으로 브라질 SBTVD 현행 지침, ABNT 원제, 검색 보조어, 브라질 법령 일자를 갱신했다. 검증 작업은 2026-10-21 KST에 했고, 기준일 표기는 2026-10-22로 정했다. 규모는 **44행·44개 기능·18문서 80개 장절 매핑**으로 그대로다. 2026-10-18판 파일은 바꾸지 않았다.

## 기준 재확인

- ATSC 공식 목록에서 현행 35문서(표준23·RP12)를 다시 대조했다. 판본은 2026-10-18과 같다. 후보표준 3건(A/324·A/344 개정, A/391)과 Code Point Registry TG3-255r9도 그대로다.
- SBTVD 공식 목록의 PDF 14개를 모두 받아 로컬과 SHA-256으로 대조했다. OG-01·OG-02는 2026년 9월판, OG-08은 2026년 10월판(4판)으로 바뀌었다. 나머지 10개는 로컬과 같다.
- 시장측정 가이드(Guia de Mensuração de Mercado, 표지 Versão 1.0 — Agosto de 2026, 11쪽)가 새로 공개되어 있었다. 이전 색인은 '미공개'로 적었다. 표지는 2026년 8월, 문서 안 버전표는 "1.0 Abril 2026"으로 서로 다르다.

## 반영 내용

- **OG-01 (2026년 9월판)**
  - 인용 조항 번호와 쪽은 그대로다. 표 이름만 숫자에서 글자로 바뀌었다(Table 1–2 → A–B, Table 9–10 → I–J).
  - 32K MP4_2 금지와 bootstrap version 0은 유지된다. ATSC 인용판은 여전히 :2025-07이다.
  - 새 Annex C는 Resolução 789를 옮겼다. 내용은 1/7 MHz 상향 이동, 250–322 MHz 부대역, 중심주파수 기준 채널 번호, 방사 마스크, 주파수 허용편차다. 허용편차는 SFN ±0.5 Hz이고, 비SFN은 100 W 이하 ±500 Hz, 100 W 초과 ±1 Hz다.
  - Annex C는 MER ≥ 30 dB와 MIMO Type A도 권고한다.
  - LDM 표현은 "up to two layers"에서 "more than one layer"로 바뀌었다.
  - §2 txid_address의 고유 할당 문구는 "shall"에서 "should"로 바뀌었다.
  - Annex B에는 DVB-P1 채널 모델이 추가됐고, 인접채널 시험 수준이 −63 dBm으로 바뀌었다.
- **A/327 행 정정:** OG-01이 A/327을 인용한 곳은 §5.5(GI), §5.6(TxID), §7(LDM)이다. FFT 크기 권고(§5.12)는 CIT-196r23을 인용한다. 2026-10-18판의 "FFT choices"와 근거 "§5.12"는 1월판에서도 맞지 않았으므로 정정했다.
- **OG-02 (2026년 9월판)**
  - 부속서 문자가 목차와 맞게 바뀌었다(링크계층 B/B.1, STL C).
  - 새 Annex A의 내용은 다음과 같다.
    - Plataforma Comum LLS를 HTTPS 브로드밴드로 전달한다.
    - rating_region 0x06과 등급 표를 쓴다. Registry의 regionIdentifier 0x06 "Brazil"과 맞는다.
    - BSID는 Anatel 호출부호에서 만든다.
    - txid_address는 0001부터 순차 할당하고, 송신소는 BSID+TxID로 식별한다.
  - 이에 따라 `sig-rrt`의 브라질 판정을 review에서 partial로 바꿨다. 근거는 비규범 OG 권고와 등록 값이며, ABNT 의무는 여전히 미확인이다.
- **OG-08 (2026년 10월판)**
  - §7.10.2는 Service Guide 모델을 A/332:2025-10(ABNT NBR 25602 Annex D)에 따른다고 적는다. 현행 A/332:2026-08보다 두 판 앞이다.
  - §7.10.1은 AMM 수집을 PRRD dpv:ServiceUsageAnalytics 동의에 묶는다.
  - §9는 원격 기기 클래스를 앱이 정할 수 있다고 적는다.
  - 쪽 앵커도 고쳤다(§9 p.16, C.6.15 p.39, BALD p.17).
  - Table C.6.1의 미디어 플레이어 제어 규칙은 A/344와 아직 비교하지 않았다.
- **메타데이터**
  - ABNT NBR 25601·25607·25608은 포르투갈어 원제를 앞에, 공식 영문 제목을 뒤에 둔다(카탈로그 Title/Secondary Title).
  - SBTVD 가이드 제목의 악센트를 복원했다(Módulo, Fórum, Mensuração).
  - TTA 공식 영문 제목의 오자 5건은 그대로 두었다. 대신 화면에 보이지 않는 `search` 보조어를 더했다. "for Terrestrial"로 수신기 행이 검색된다.
  - 오자 문서 중 3건(TTAR-07.0010, TTAK.KO-07.0063/R1, TTAK.KO-07.0119/R3)은 어느 행에도 연결되어 있지 않다.
- **법령**
  - Portaria 10.693의 공표·시행일은 2023-10-19다. 근거는 MCom SERAD 목록과 DOU 검색 추출 제3조다. DOU 원문 파일은 받지 못했다.
  - Resolução 789의 시행일은 2026-08-12로 적고, LC 95/1998 제8조 §1에 따른 산정값임을 함께 표시했다.

## 검증

- `tools/build_data.py --check`: 정본 JSON과 생성 JSON/JS가 일치한다.
- `tools/test_dashboard.py --browser`: 격리 Chromium에서 44행·44개 기능을 모두 펼쳤고, 오류 0건, 1440/1024/390 px와 어두운 화면에서 페이지 넘침 0건이다.
- 검색 회귀 검사에 3건을 더했다: "for Terrestrial", "Mensuração", "rating_region".
- 단일 HTML은 네트워크를 막은 상태에서 열린다.
- 각 행과 기능의 검토 이력에는 두 가지를 구분해 적었다. 하나는 2026-10-22에 바뀐 브라질 근거이고, 다른 하나는 2026-10-18 검토에서 그대로 이어받은 조항 판단이다.
- 이번 갱신은 바뀐 출처와 그 인용만 다시 대조했다. 모든 조항을 새로 감사한 것은 아니다.

## 미확인 범위

ABNT 규범 전문, OG-01 Annex C와 본문 §5.3·Annex A/B 사이의 내부 불일치(허용편차·MER 40 dB 표현), 그리고 OG-08 미디어 플레이어 규칙의 ATSC 대조는 남아 있다. TTA 문서 판본은 2026-10-18 기준을 유지했다. 이번에 TTA 상세 페이지를 다시 열지는 않았다. 결과는 로컬 검증본이며, 공개 사이트 배포나 다른 기기의 수신 확인을 뜻하지 않는다.
