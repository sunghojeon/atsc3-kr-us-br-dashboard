# 2026-10-18 비교 자료 수정 및 검증

최신 ATSC 중심 전체 검토 후 비교 내용·생성기·화면을 함께 수정했다. 기존43행·33개 기능·64개 장절 매핑을 검토하고, A/200 및 빠진 세부 비교를 보완해 **44행·44개 기능·18문서80개 장절 매핑**으로 정리했다.

## 반영 내용

- A/362를2026-09로 갱신하고 DRM 요청·대기·서비스 수 제한·오류·조회 변경을 기록했다. A/327 편집 정정 파일과 A/337 실제04판을 구별했다. 후보 개정은 확정판과 분리했다.
- 패리티 인덱스 끝점, MIMO pilot 값·누락행, L1 시간·UTC 예제, LDM 표의 실제 존재를 반영했다. 한국 DSTP/ALPTP 부록의 비규범 지위를 명시했다.
- SystemTime namespace·자료형·범위, ROHC 전처리, 서비스별 SLS 필수성, 서명과 암호화를 구분했다. 한국 code10·VIT/CPT와 브라질 공개 코드 할당을 반영했다.
- HFR 수식·HLG·MPEG-H 차이를 교정했다. A/345의 VVC·선택적 LCEVC, ATSC3D 조항, 한국 컴패니언의 A/338:2017 §5.6 직접 준용을 반영했다.
- 미국 고정 편입판·일부 의무 만료, 브라질 Resolução789 서명/공표/시행 규칙과250–322MHz 범위를 구분했다. 미확인 법령 일자는 추정하지 않았다.
- 상위 Same/하위 Partial 충돌과 미검토/부재 혼동을 제거했다. 세부 판정 이유·권고·미확인 범위를 표시하고 세부 조항 검색을 보완했다.
- 행 식별자 기반 펼침 상태, 키보드 버튼·필터 초기화·상태 알림을 보완했다. 좁은 화면은 표 안에서 가로 스크롤하며 페이지 전체가 넘치지 않도록 수정했다.
- 빌드를 Git 관리 JSON만으로 재현하도록 변경했다. 원문 PDF·로컬 색인·로그인 상태에 의존하지 않는다. 오프라인 단일 HTML 내보내기를 추가했다.

## 검증

`tools/build_data.py --check`로 정본과 생성 JSON/JS의 정확한 일치를 검사한다. `tools/test_dashboard.py --browser`는44행·44개 기능을 실제 Chromium에서 모두 펼쳐 판정 이유·권고 표시, 검색·필터·키보드·모바일·어두운 화면·단일 HTML을 검사한다. 별도 사본에서 원문 폴더 없이 재빌드해 휴대성을 검증했다.

수정 전 파일과 원문 PDF 해시는 별도 검토 기록에 보존했다. 기존 PDF를 덮어쓰지 않고 새 현행 파일을 다른 이름으로 추가했다. ATSC35문서의 판본 확인과 관련 조항 비교를 모든 문장에 대한 동등성 인증으로 해석해서는 안 된다.

## 미확인 범위

ABNT 규범 전문과 일부 MCom 원문 일자는 확인하지 못했다. 공개 OG로 확인한 사실과 ABNT 의무 미확인을 함께 남겼다. 전체 XML 스키마 차분 및 장비·방송망 상호운용은 수행하지 않았다. 결과는 로컬 검증본이며 공개 사이트 배포·다른 기기의 수신 확인을 뜻하지 않는다.
